## Why `artifacts/` is not committed

Forty pickles, tens of megabytes. Unpickling executes, so committing them would put forty executable payloads in every clone -- which is why `serialization.deserialize` refuses an artifact whose sha256 does not match in the first place. The evidence is that record, not the bytes: `artifacts.json` carries each model's hash, size and `round_trip_exact` flag, and the run is deterministic, so regenerating the directory and comparing hashes is the check.

- Not comparable to A2. Different design, different sample size, and a different data snapshot.
